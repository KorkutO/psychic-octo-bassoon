# Value Atlas Studio

A professional static website for publishing PNG maps, interactive research pages, and visual explanations of academic or social data projects.

## Structure

- `index.html` - main public website
- `styles.css` - visual design
- `script.js` - interactive atlas preview
- `assets/maps/` - place PNG map exports here
- `projects/` - place future interactive mini-sites here

## Publishing with GitHub Pages

In GitHub, open the repository settings, go to **Pages**, choose **Deploy from a branch**, select `main`, select `/root`, then save.

After GitHub builds the site, it should be available at:

`https://korkuto.github.io/psychic-octo-bassoon/`
