Free sources

Built to stay free and legally clean.

Puzzles The expandable puzzle source is the Lichess puzzle database, released under CC0 public domain terms.

Rules Move legality is checked in the browser with chess.js, an open-source BSD-2-Clause chess rules library.

Hosting The site is static and can stay on GitHub Pages for free.
